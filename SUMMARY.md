New `updated/` is a separately labeled runnable numerical replay. `build_headless.py` verifies source hashes and compiles the unchanged submitted Reconstructor.java/CalibrationFile.java directly with explicit compile-only platform shims. Four actual private methods execute through reflection on supplied frames/calibration; capture/UI/OpenCV calls are unsupported. Both numerical modes stop before Clear's coordinate clipping and OpenCV Z-only median. `validation/headless-build.json` records the precise scope.

Independent camera-ray/surface intersections, projector forward projection and geometric shadow tests generate 13 deterministic scenes. They cover plane/tilted/sphere/step, rotated and translated calibration, nonlinear radial correction with nonzero center/aspect, projector shadows, noise, high/low contrast, corrupt bits, zero baseline and radial center. A corrected unsigned/scaled/guarded adaptation is separate from historical behavior. Its clean scene RMSEs are 3.18–5.39 mm at 64 × 48 with a ten-bit virtual projector; all illuminated points are retained. Corrupt bits still produce large finite outliers. These are supplied-calibration synthetic results in virtual metres, not real hardware performance. Full conditions, hashes, images, PLY and interactive report live in updated/results/. Android replay assets contain the same independently generated captures.

Thirteen tests in `updated/tests/` exercise actual unchanged Java methods, independent geometry, all 1,024 unsigned Gray codes, pixel/matrix input guards, occlusion/noise/degeneracy, calibrated rays and documented failures. Oracle projector coordinates isolate original triangulation to within 20 micrometres numerical error over the tested full field of view; that is not scanner accuracy. `python3 updated/run_checks.py` refreshes validation/numerical-tests.json. Avoid compiling shared headless class output concurrently with another validation consumer.
